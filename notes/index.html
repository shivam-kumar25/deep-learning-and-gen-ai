Deep Learning and Gen AI

Deep learning from the single neuron to convolutional networks, transfer learning and U-Net, built up one idea at a time. Every code cell runs on a live Python kernel with PyTorch on this computer: run it, change it, break it, and run it again.

The course is five subjects in four tracks, in the order they build on each other. Notes are numbered across the whole course, so "note 06" means the same page wherever it is mentioned.

D1
Neural Network Foundations

What deep learning is and why it works; the neuron from biology to the perceptron; multi-layer perceptrons, the forward pass and the universal approximation theorem; activation functions.

notes 01–04
D2
Training Neural Networks

Loss functions, gradient descent and its variants (momentum, Adam), backpropagation worked by hand, the XOR network end to end, and regularisation against overfitting.

notes 05–09
D3
PyTorch

Tensors and every operation on them, autograd, NumPy and the GPU; the PyTorch workflow: data, model, loss, optimiser, training and testing loops, saving and loading.

notes 10–12
D4
Convolutional Networks

Why images need CNNs, convolution derived and worked by hand, kernel size, stride and padding, pooling, batch norm and dropout, a CNN trained on Fashion-MNIST, and AlexNet, VGG, GoogLeNet and ResNet.

notes 13–19
